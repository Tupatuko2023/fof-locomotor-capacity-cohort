# Reproducibility Scope

Realistic goals for this repository are **partial computational reproducibility on two levels**:

1. **Full structural and rendering reproducibility with public materials**
   External researchers can inspect the directory structure, analysis steps, variable definitions, model formulas, table/figure bindings, and render the manuscript using published aggregated results and synthetic data.

2. **Full numerical analysis reproducibility only in a restricted environment**
   The actual participant-level analyses can only be reproduced in an approved, secure environment using the original registry data and the analysis scripts provided by the authors.

Public repository focuses on documenting the pipeline and making everything transparent, minus the patient-level data.
