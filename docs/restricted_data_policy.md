# Restricted Data Policy

According to the manuscript, the analyses are based on sensitive geriatric registry data, which is not publicly available. Data may be obtained from the corresponding author upon reasonable request and with permission from the registry controller.

Therefore, this public GitHub repository **must not** contain:
- Raw data.
- Pseudonymized participant-level data.
- Analysis-ready participant-level files.
- Participant identifiers.
- Row-level datasets containing model frames.

Use synthetic data for pipeline validation.
