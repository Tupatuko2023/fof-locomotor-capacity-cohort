# Data Directory

This directory is intended to store data needed for reproducing the analysis.
However, **no restricted patient data is ever allowed in this repository**.

## Rules
- ONLY synthetic or clearly non-restricted, non-identifiable test data is allowed in the Git repository.
- Synthetic data should be placed in the `synthetic/` subdirectory.
- If real data is accessed locally during analysis in a secure environment, it should be placed in `restricted/` or `raw/` and these directories are ignored by Git.

**DO NOT COMMIT REAL DATA.**
